# Toluwalope Portfolio

Personal product design portfolio for Toluwalope Jinadu.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

The site is configured for GitHub Pages at /Toluwalope-portfolio/ and deploys automatically through GitHub Actions after changes land on the main branch.

## Personalize

The main portfolio content lives in src/App.tsx, the visual system lives in src/index.css, and portfolio images are in public/portfolio.
